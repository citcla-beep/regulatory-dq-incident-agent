# Regulatory DQ Incident Agent

When a data quality check fails in a regulatory reporting pipeline, finding the
root cause is still manual work: an analyst has to trace the failing record back
through every transformation to the point where the error was introduced.

This project builds a small end-to-end reporting pipeline on synthetic
cross-border payment data, with data quality tests at every layer, and an AI
agent that reads the failed tests, walks the data lineage upstream and drafts an
incident report for the analyst.

## Status

Work in progress. The repository is being built milestone by milestone.

## Data

All data is synthetic and generated by code in this repository. The data model
is inspired by publicly available EU rules on cross-border payment reporting.
No real, internal or customer data is used.
